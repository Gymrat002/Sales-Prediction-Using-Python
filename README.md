# 📈 Sales Prediction Using Python

## 📌 Project Overview

This project is developed as **Task 5** of the **OASIS INFOBYTE Data Science Internship**.

The objective of this project is to predict product sales based on advertising expenditures across different media channels using Machine Learning techniques.

---

## 🎯 Objective

To build and compare Machine Learning regression models that can accurately predict sales using advertising budgets for TV, Radio, and Newspaper.

---

## 📊 Dataset

The dataset used in this project is the **Advertising Dataset**.

### Features

- TV Advertising Budget
- Radio Advertising Budget
- Newspaper Advertising Budget

### Target

- Sales

---

## 🛠 Technologies Used

- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## 📈 Exploratory Data Analysis (EDA)

---

## 🤖 Machine Learning Models

The following regression models were trained:

1. Linear Regression
2. Random Forest Regressor

---

## 📋 Model Evaluation

The models were evaluated using:

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R² Score

The best-performing model was selected based on evaluation metrics.

---

## 📊 Feature Importance

Feature importance and regression coefficients were analyzed to identify the most influential advertising channel affecting sales.
